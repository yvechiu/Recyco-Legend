# 瑞賽可傳奇 · Recyco Legend

以邱郁棻（Yu-Fen Chiu）的《科學傳播期末書面報告\_遊戲企劃書》為原作，依附帶 GDD 第 10 節實作的 **Phaser 3 + TypeScript + Vite 單人網頁遊戲**。預設繁體中文，適合國小三、四年級。原始文件是一份企劃，這個儲存庫才是可執行的網頁改編。

## 啟動

需要 Node.js 20.19+（已在 Node.js 24.19.0 / npm 11.9.0 驗證）。不需要後端、帳號、API 金鑰或外部字型服務。

```sh
npm ci
npm run dev
```

開啟終端顯示的 Vite 位址。正式版本：

```sh
npm run build
npm run preview
```

`dist/` 是完整靜態網站；不要直接用 `file://` 開啟，請使用 HTTP 伺服器。雲端環境若無法寫入預設 npm 快取，可使用 `npm ci --cache /tmp/recyco-npm-cache`。

## 完整玩法

1. 輸入 1–12 字名字、選擇四種原企劃勇士外觀。聽完國王溫與智者慧的委託。
2. 從循環島地圖拜訪瑞賽可村三位村民、閱讀焚山四種產物的導覽。
3. 在克林湖完成垃圾流程排序與廢棄支線、焚化產物配對。答錯有說明，可以無限調整。
4. 女神給出「五位數」與魔法地圖。讀取星號橫軸 160、縱軸 80，組成入口密碼 **16080**。
5. 進入森林，閱讀說明後用**上下左右鍵／WASD 逐格走動，空白鍵互動**；手機使用畫面方向鍵。樹木、水池、石頭與分類桶不能穿過。走近全部九件垃圾後撿拾，從背包選取物品，再走到高／中／低回收價值桶旁分類。滑鼠點地圖物品或下方搜尋按鈕也能自動尋路，不會隔空拾取或投入。錯誤扣一條生命，仍會自動投入正確桶；生命耗盡可重試，保留前一任務。南方箭頭出口可返回島嶼。
6. 挑戰廢棄怪：**左滑／←／左按鈕＝資源回收；右滑／→／右按鈕＝一般垃圾**。答對攻擊魔王，答錯勇士受傷。沒有倒數。
7. 打贏迎來好結局並向國王許願；打輸迎來壞結局。兩種結局都可再戰、回地圖或從頭開始。

目前先將**森林清理**做成類似經典俯視 RPG 的步行關卡；村落、女神和島嶼仍沿用點選導覽，魔王戰沿用左右分類。已完成遊戲的玩家可在地圖按「重玩森林步行關」，重置森林生命／九件物品與本次結局，但保留名字、外觀、女神線索、入口及願望文字。重新進入森林時勇士回入口，已撿取／分類進度照常保留。

所有核心互動都可點擊、觸控，或用 Tab + Enter／空白鍵操作。外觀選項可用鍵盤方向鍵切換。魔王戰另支援左右方向鍵與真實觸控滑動。音效未加入，預設靜音。不使用閃爍效果，尊重 `prefers-reduced-motion`。

## 存檔

使用 `localStorage` 的 `recyco-legend-v1`，沒有任何伺服器或分析追蹤。自動保存名字、外觀、探索、兩題線索、解鎖、背包、分類進度、森林生命與結局／願望。重新整理後從首頁「繼續冒險」。戰鬥再次進入時重設雙方血量；關閉分頁不保留戰鬥中的血量。

首頁「重設所有進度」有確認視窗。損壞／不支援版本的存檔會安全略過；瀏覽器封鎖儲存時仍可完成本次遊戲，但不保證離開後保留進度。

## 原稿與改編界線

- 原稿確認：兩族／鞍太／國王溫／智者慧／女神／廢棄怪的故事、兩道女神題的內容、五位數線索、魔法地圖、16080、九件物品回收價值、15 種部件分類、正誤互相扣血、好壞結局與許願。
- 原圖：四種勇士、國王／智者、女神、廢棄怪、魔法地圖，從使用者提供 PDF 擷取，保存在 `public/assets/original/`。沒有把新圖冒稱原稿作品。資產來源與權利限制見該資料夾的 `README.md`。
- 本次新增：Phaser 向量場景、物品小圖、森林像素步行示意造型、俯視格子地圖／鏡頭跟隨／碰撞、地圖點選導覽、簡化對話、精確操作說明與存檔。主要對話來源標記在 `dialogues.ts`。原稿「丟寶物召喚女神」被改為尊重環境、不丟物品。
- 實作平衡值：勇士 HP 5、魔王 HP 8、正誤傷害 1、森林生命 3、固定種子洗牌、550ms 出招間隔。集中在 `balance.ts`，**不是原稿數值**。題庫耗盡會以新種子重新洗牌。
- 科學澄清：原稿「廢氣用於發電」在題目與導覽明確改寫為**燃燒熱能發電，廢氣仍須淨化**。底渣及廢水需合格處理後再利用。
- **教育限制：歷史企劃的回收價值及分類不是現行臺灣通用回收規則。所有分類保留原作者的遊戲設計，標記待環境教育專家複核，特別是養樂多鋁膜、彩色筆筆蓋／筆桿等。日常處理請依所在地清潔隊公告。** 遊戲首頁說明、森林、魔王戰及頁尾均可看到提醒。

原稿圖片中的完整多分支流程改為三步排序＋廢棄支線選擇；連線配對改為可供鍵盤和觸控操作的下拉配對。地圖座標讀法加上文字提示，避免只靠小字圖片或視覺判讀。沒有假稱新增的指引為逐字原文。完整核對筆記見 [docs/SOURCE_ADAPTATION.md](docs/SOURCE_ADAPTATION.md)。

## 測試

```sh
npm run build
npm test
```

Playwright 針對 **正式 build 的 preview** 測試。優先使用系統的 `/usr/bin/chromium`，也可用 `CHROMIUM_PATH` 指定執行檔；無此系統路徑時使用 Playwright 管理的瀏覽器。一般電腦可先 `npx playwright install chromium`，再執行測試。測試包含完整新遊戲通關、正誤題目回饋、九件分類、魔王雙結局、森林重試、存檔、鍵盤與手機觸控。具體實跑結果及限制記於 [docs/VALIDATION.md](docs/VALIDATION.md)。

## 部署

Vite 使用相對 `base: './'`，可部署於子路徑（例如 GitHub Pages 的 `/Recyco-Legend/`）。不需要 SPA rewrite，遊戲場景不修改 URL。

- **GitHub Pages：** 在儲存庫 Settings → Pages 選 GitHub Actions。執行本儲存庫的 **Deploy game to GitHub Pages** 手動工作流程，建置並發布 `dist/`。需要你有儲存庫／Pages 權限；本次未代為推送或公開發布。
- **Vercel／Netlify：** 匯入儲存庫，建置指令 `npm run build`，輸出目錄 `dist`，安裝指令 `npm ci`，Node 24。沒有必要設定 secrets。
- **其他靜態網站主機：** 上傳 `dist/` 的全部檔案，保留相對目錄及大小寫。

發布後請用真正部署網址完成一次新遊戲與重新整理續玩。此處的測試證據屬於目前環境的本機正式預覽，不代表已取得公開網址或驗證其他主機。
