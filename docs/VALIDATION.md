# 實作與驗證結果

日期：2026-10-22（Asia/Taipei）。這份紀錄描述實際執行結果，不代表公開部署或實機手機認證。

## 已交付

完成可玩的 Phaser 3 + TypeScript + Vite 靜態前端遊戲，包括角色建立、四種原稿外觀、王宮劇情、五個地標的島嶼地圖、村落和焚山學習、女神流程排序／分支與配對題、兩線索及 16080 入口、九件拾取與背包、三種回收價值分類與生命、魔王 15 部件分類牌庫、雙方血量、好壞結局、許願、重試／重玩及本機存檔。

先完成標題 → 劇情 → 地圖 → 村落互動／完成回饋的可玩切片並建置與測試，之後擴展完整關卡。

- Node.js 24.19.0、npm 11.9.0。
- Phaser 3.90.0、TypeScript 5.9.3、Vite 6.4.5、Playwright 1.58.2。
- Chromium 154.0.8037.57，Linux headless。桌面視窗 1280 × 1000；手機模擬 390 × 844 與 360 × 800。
- 所有指令的工作目錄：`/workspace/Recyco-Legend`。

| `npm ci --cache /tmp/recyco-npm-cache --no-audit --no-fund` | 乾淨安裝成功；重用鎖定依賴與校驗，不依賴全域 Phaser／Vite |

## 14 個測試實際涵蓋

1. **首個可玩切片**：從新玩家輸入到劇情、地圖、三位村民互動，確認完成回饋及 localStorage。
2. **完整新遊戲通關**：實際走完全部劇情、兩處學習、流程排序與分支、產物配對、密碼、九件拾取與分類、鍵盤魔王戰、好結局與願望。包含錯誤排序／配對／密碼與一次錯誤分類的改正路徑；監聽未捕捉 JavaScript 錯誤與失敗資源請求，均無發現。
3. **壞結局與重戰**：五次錯誤讓勇士 HP 歸零，進壞結局；重戰確認恢復 5 HP，再以按鈕獲勝。
4. **森林失敗與續玩**：錯三次耗盡生命、重試保留女神與入口，撿物後重新整理可續用背包。
5. **進度鎖與先備探索**：未取得兩線索時不能進森林；未讀村落／焚山時有可操作的前往指引。
6. **損壞存檔及重設**：無效 JSON 安全恢復；確認後可刪除玩家與進度。
7. **儲存受阻**：模擬讀寫 localStorage 拋錯，仍能玩到地圖並顯示無法儲存的提醒。
8. **鍵盤操作**：用鍵盤選外觀、開始、推進劇情與進入村落。
9. **來源資料與判定**：九件原稿價值、15 部件、五種資源回收部件、專家複核旗標、固定種子牌庫的完整性／重複性、流程及配對正誤判定。
10. **手機滑動與點選**：使用 Chromium DevTools Protocol 送出真正的 touchStart／touchMove／touchEnd，驗證左、右兩種滑動的 HP 變化，再以觸控進村落；確認沒有水平頁面溢出。
11. **舊版存檔**：不支援版本安全略過，不顯示虛假的可繼續進度。
12. **中斷與視窗**：說明視窗開啟時方向鍵不攻擊；出招後回地圖不觸發舊戰鬥的結局，重入重置雙方 HP。
13. **360px 手機完整清理**：以觸控逐一完成九件拾取／分類，地圖五個地標的矩形互不重疊，沒有水平溢出，原稿魔法地圖可開啟且圖片確實載入。
14. **子路徑靜態部署**：在 `/Recyco-Legend/` 開啟正式檔案，選角、開始、原稿角色圖均正常；確認 CSS 原圖背景相對 URL 及資源沒有 404。
