# 實作與驗證結果

日期：2026-10-22（Asia/Taipei）。這份紀錄描述實際執行結果，不代表公開部署或實機手機認證。

## 已交付

完成可玩的 Phaser 3 + TypeScript + Vite 靜態前端遊戲；本次將瑞賽可村更新為可步行拜訪三位 NPC 的村莊，包括角色建立、四種原稿外觀、王宮劇情、五個地標的島嶼地圖、村落和焚山學習、女神流程排序／分支與配對題、兩線索及 16080 入口、九件拾取與背包、三種回收價值分類與生命、魔王 15 部件分類牌庫、雙方血量、好壞結局、許願、重試／重玩及本機存檔。

先完成標題 → 劇情 → 地圖 → 村落互動／完成回饋的可玩切片並建置與測試，之後擴展完整關卡。後續先將森林改為逐格步行、障礙碰撞、鏡頭跟隨與鄰格互動；這次再把村落改為三位 NPC 的實體地圖、回覆選項、對話與分別保存的手記。女神及焚山保留原介面。

- Chromium 154.0.8037.57，Linux headless。桌面視窗 1280 × 1000；手機模擬 390 × 844 與 360 × 800。

## 24 個測試實際涵蓋

1. **首個可玩切片**：從新玩家輸入到劇情、地圖、三位村民互動，確認完成回饋及 localStorage。
2. **完整新遊戲通關**：實際走完全部劇情、兩處學習、流程排序與分支、產物配對、密碼、九件拾取與分類、鍵盤魔王戰、好結局與願望。包含錯誤排序／配對／密碼與一次錯誤分類的改正路徑；監聽未捕捉 JavaScript 錯誤與失敗資源請求，均無發現。
3. **壞結局與重戰**：五次錯誤讓勇士 HP 歸零，進壞結局；重戰確認恢復 5 HP，再以按鈕獲勝。
4. **森林失敗與續玩**：錯三次耗盡生命、重試保留女神與入口，撿物後重新整理可續用背包。
5. **進度鎖與先備探索**：未取得兩線索時不能進森林；未讀村落／焚山時有可操作的前往指引。
6. **損壞存檔及重設**：無效 JSON 安全恢復；確認後可刪除玩家與進度。
7. **儲存受阻**：模擬讀寫 localStorage 拋錯，仍能玩到地圖並顯示無法儲存的提醒。
8. **鍵盤操作**：用鍵盤選外觀、開始、推進劇情與進入村落。
9. **來源資料與判定**：九件原稿價值、15 部件、五種資源回收部件、專家複核旗標、固定種子牌庫的完整性／重複性、流程及配對正誤判定。
10. **手機滑動與點選**：使用 Chromium DevTools Protocol 送出真正的 touchStart／touchMove／touchEnd，驗證左、右兩種滑動的 HP 變化，再以觸控進村落；確認沒有水平頁面溢出。
11. **舊版存檔**：不支援版本安全略過，不顯示虛假的可繼續進度。
12. **中斷與視窗**：說明視窗開啟時方向鍵不攻擊；出招後回地圖不觸發舊戰鬥的結局，重入重置雙方 HP。
13. **360px 手機完整清理**：以觸控逐一完成九件拾取／分類，地圖五個地標的矩形互不重疊，沒有水平溢出，原稿魔法地圖可開啟且圖片確實載入。
14. **子路徑靜態部署**：在 `/Recyco-Legend/` 開啟正式檔案，選角、開始、原稿角色圖均正常；確認 CSS 原圖背景相對 URL 及資源沒有 404。

15. **步行鍵盤路線**：方向鍵逐格移動，空白鍵撿拾與桶邊投入；樹木、水池不能穿過，南方出口返回島嶼。
16. **地圖可達性**：驗證九件物品與三桶都有從入口出發的合法鄰格路線；沒有穿牆、斜切、越界或走進水池／石頭。
17. **輸入生命週期**：長按方向鍵後放開會停止；說明視窗、視窗失焦與重新進入場景不留下連續移動或重複監聽。
18. **手機步行**：觸控方向鍵移動、互動按鈕拾取；放開後不漂移，頁面無水平溢出。
19. **已通關者重玩與畫布操作**：重玩森林保留女神線索、入口與願望，清除森林和本次結局；直接點 Phaser 畫布中的布丁杯，勇士必須真的走到鄰格才拾取。

20. **NPC 對話與部分進度**：從遠處不能隔空交談；方向鍵走近並按空白鍵開啟，村民本身不能穿過。Esc 或中途告辭不誤算完成，最後確認才保存一份手記；重新整理保留部分進度，重聊不重複計數。
21. **畫布上的居民與村莊碰撞**：直接點選 Phaser 畫布中的阿禾，角色自動走到鄰格才打開對話；房屋不能穿過；走出村莊再進入不留下對話框或重複輸入。
22. **舊存檔相容**：舊版本已完成村落者自動補齊三份 NPC 手記，既有女神／森林進度保留。
23. **手機村民互動**：使用觸控方向鍵、交談按鈕、回覆及下一句完成手記；對話期間方向鍵不移動角色，視窗及頁面沒有水平溢出。
24. **村莊可達性與教材**：三位 NPC 都有可達的鄰格路線，房屋／水池／居民不能穿過；對話為改寫內容，手記保留收集與分類流程、回收價值不足和兩族共處等主題。

## 視覺檢查與修正

已檢視 Playwright 擷取的桌面標題、王宮劇情、好結局，以及手機魔王戰／地圖畫面；先前另檢視桌面與手機森林步行畫面；本次增加村莊、NPC 頭像、選項與分頁對話的桌面／手機畫面。修正了外觀 radio 點擊區被圖像蓋住、原稿四外觀的 CSS 裁切位置、首頁文字背景對比，以及窄螢幕地標換行造成遮疊的問題。新增的地標不重疊斷言也已在最後一輪通過。

## 建置輸出與限制

- `dist/` 已產生，可由靜態主機提供。主要程式約 79.4 kB、CSS 約 29.1 kB；Phaser 獨立 chunk 約 1.48 MB（gzip 約 340 kB）。完整輸出含原圖約 3.7 MB。
- Vite 有 **Phaser chunk 超過 500 kB 的非阻擋警告**。這不是型別或建置錯誤；Phaser 已獨立拆包。本次沒有為了消除警告而隱藏它或移除遊戲功能。
- 首版及森林步行版先前已依使用者要求推送 GitHub；這次村莊 NPC 更新尚未推送，也未執行 GitHub Pages／Vercel 的外部工作流程。未在本次工作中查驗既有公開網站；已提供手動 Pages 工作流程及 README 部署步驟。
- 手機測試屬於 Chromium 觸控模擬；未在實體 iOS Safari、Android 裝置、Firefox 或螢幕閱讀器上獨立驗證。鍵盤與語意化 DOM 已檢查，但沒有宣稱完整 WCAG 認證。
- 歷史分類完整保留原企劃，仍待環境教育專家複核，不能直接當作現行地方垃圾處理規則。科學澄清與改編差異見 `SOURCE_ADAPTATION.md`。
- 沒有聲音、語音、後端或雲端存檔；這些符合 GDD 的 MVP 範圍。本機儲存遭封鎖時，不保證分頁關閉後恢復。
