## 建置輸出與限制

- `dist/` 已產生，可由靜態主機提供。主要程式約 79.4 kB、CSS 約 29.1 kB；Phaser 獨立 chunk 約 1.48 MB（gzip 約 340 kB）。完整輸出含原圖約 3.7 MB。
- Vite 有 **Phaser chunk 超過 500 kB 的非阻擋警告**。這不是型別或建置錯誤；Phaser 已獨立拆包。本次沒有為了消除警告而隱藏它或移除遊戲功能。
- 首版及森林步行版先前已依使用者要求推送 GitHub；這次村莊 NPC 更新尚未推送，也未執行 GitHub Pages／Vercel 的外部工作流程。未在本次工作中查驗既有公開網站；已提供手動 Pages 工作流程及 README 部署步驟。
- 手機測試屬於 Chromium 觸控模擬；未在實體 iOS Safari、Android 裝置、Firefox 或螢幕閱讀器上獨立驗證。鍵盤與語意化 DOM 已檢查，但沒有宣稱完整 WCAG 認證。
- 歷史分類完整保留原企劃，仍待環境教育專家複核，不能直接當作現行地方垃圾處理規則。科學澄清與改編差異見 `SOURCE_ADAPTATION.md`。
- 沒有聲音、語音、後端或雲端存檔；這些符合 GDD 的 MVP 範圍。本機儲存遭封鎖時，不保證分頁關閉後恢復。

## 森林分類錯誤後可重新選桶

分類錯誤仍扣一條生命，但不再自動加入 `sorted`，物品與選取狀態留在背包，顯示材質／回收價值提示後可選別的桶重試。只有選對才移出背包並計入完成進度；最後一件選錯也不會觸發清理完成。原本三條生命用盡後重新清理的流程維持，已有存檔進度不追溯重置。
